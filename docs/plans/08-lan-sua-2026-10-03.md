## 1. §3.2 dòng 152 — nhánh 1 frame theo quy ước kế hoạch 11 [LS-1003]

Thay khối ② ở §3.2 (`:149-153`) bằng:
```
    ② _activity(aspect):
         kn, vn = _normalise(cửa sổ ≤ activity_window_s, aspect)          (không đổi)
         n ≥ 2: dt = t_n − t_{n−1};  fps_last = 1 / max(dt, speed_min_dt_s)
         n = 1: fps_last = 0.0   # one frame: no rate is measured; hand_activity's speed term is empty,
                                 # so the result does not depend on fps   (quy ước kế hoạch 11 §3.3)
         left, right = hand_activity(kn, vn, fps_last, cfg_ckpt);  return left[-1] or right[-1]
```

  (`MIN_SERVING`, guard `:57`); `fps_last = 30.0` là binding tên chứa token `fps` (METRIC_TOKENS, guard `:139-141`) nhận số gõ tay ⇒ finding D-binding mới
  không đăng ký được ⇒ guard ĐỎ. `0.0` thuộc `SENTINELS` (guard `:103`) ⇒ không là finding; cùng quy ước "0.0 = chưa đo được" với 11 (`realtime_demo.mean_fps`,
  `landmark_extractor` fps, `harmonized_live.py:113`).
- **Hành vi khi n = 1** (cửa sổ chỉ còn 1 frame: frame đầu phiên, sau `reset()`, sau khoảng trống `> stream_gap_s` xóa cửa sổ, hoặc mọi trường hợp cửa sổ còn
